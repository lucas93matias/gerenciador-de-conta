#### ****Relatório – Sistema de Gerenciamento Bancário em Java****

****1\. Introdução****

Este projeto tem como objetivo desenvolver um sistema simples de gerenciamento bancário utilizando a linguagem Java. A aplicação permite o cadastro de usuários, criação de contas bancárias, depósitos, saques, consultas de saldo e listagem de contas. O foco principal é a aplicação dos conceitos de Programação Orientada a Objetos (POO), utilizando classes, encapsulamento e interações entre objetos.

****2\. Metodologia****

O sistema foi desenvolvido em Java, utilizando a IDE NetBeans, com foco em estruturas básicas como Scanner para entrada de dados, e classes organizadas conforme os princípios de coesão e responsabilidade única. O sistema é composto pelas seguintes classes:

- Usuario: contém os dados pessoais do titular.
- Conta: representa uma conta bancária e suas operações.
- Banco: gerencia todas as contas do sistema.
- GerenciaBanco: classe principal que implementa o menu interativo com o usuário.

As ações do sistema são realizadas via terminal, utilizando menus numéricos para navegação e escolha de funcionalidades.

****3\. Resultados****

Com a aplicação em execução, o usuário é capaz de:

- Criar uma conta com nome, sobrenome e CPF;
- Realizar depósitos e saques;
- Consultar o saldo da conta através do CPF;
- Listar todas as contas cadastradas no sistema.

Essas funcionalidades foram testadas com sucesso, validando o funcionamento correto dos métodos de cada classe, e simulando interações reais de um sistema bancário.

****4\. Conclusão****

O projeto atendeu aos objetivos propostos, demonstrando na prática o uso da Programação Orientada a Objetos em Java. Foram aplicados conceitos de encapsulamento, reuso de código, modularização e abstração de entidades do mundo real. Este exercício proporcionou uma base sólida para projetos mais avançados que envolvam persistência de dados, interfaces gráficas ou conexão com bancos de dados.
